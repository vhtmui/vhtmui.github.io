# 单芯（单纤）光模块与双纤光模块对比

一般光模块有两个端口，TX为发射端口，RX为接收端口；而单芯光模块是利用WDM技术，实现一根光纤双向传输光信号。单芯光模块有许多别称：单纤双向光模块、BIDI光模块、还有单模单芯光模块、单芯双向光模块、单纤双向传输模块等。单芯光模块只有1个端口，通过光模块中的滤波器进行滤波，同时完成不同波长光信号的发射和接收，因此单芯光模块必须成对使用。

　　单芯光模块最常用的波长为1310nm/1550nm，1310nm/1490nm，1510nm/1590nm。单芯光模块是仅有一个光纤端口的光模块产品，只用插一根光纤就能同时进行光信号的发射和接收，是一种节省光纤资源的解决方案。就像马路上由隔离带隔开的正反两个方向的车道，两边的车辆在各自的车道上行驶，互不干扰。而常规的光纤传输是单纤单向的，这样要实现双向的通信就需要两根光纤。相比较而言，单纤双向技术只使用一根光纤就完成了原来两根光纤才能完成的工作，将现有光纤的传输量提高了一倍，从而大大节省了光纤资源。

## 单芯光模块应用环境

单芯光模块的特点

- 　1、集成1550/1490nm或1550/1310波分复用器
- 　2、单电源+3.3V/+5V供电
- 　3、LVPECL/PECL数据接口
- 　4、工作温度-40℃~+85℃（工业级）0℃~+70℃
- 　5、符合GR-468-CORE要求
- 　6、符合Laser Class 1，达到IEC60825-1要求
- 　7、可供应符合RoHS规范要求的产品

## 单芯光模块的分类

### 一、BIDI SFP光模块

　　BIDI-SFP光模块：BiDi（Bidirectional）即：单纤双向。它是利用WDM（波分复用）技术，发送和接收两个方向的不同中心波长，从而实现一根光纤双向传输光信号。传输距离在40KM以内两种常用方案：1310nm/1550nm：1310nm/1490nm；传输距离在40KM以上的常用方案：1550nm/1490nm。

### 二、BIDI SFP+光模块

　　SFP+ BIDI单纤双向万兆光模块，支持10G传输速率，发射部分采用低抖动、高性能的 1330nm/1270nm DFB激光组件（1330/1270纳米波长），可支持最大传输距离10km。支持热插拔，单纤双向传输，带数字诊断监控功能，支持商业级温度范围（ 0℃~+70℃）。 主要应用在10GBASE LR Ethernet以太网，10G LW Fibre Channel光纤通道等领域。

### 三、BIDI XFP光模块

　　BiDi XFP 10km单纤双向万兆光模块，支持10G传输速率，发射部分采用低抖动、高性能的 1330nm/1270nm DFB激光组件（1330/1270纳米波长），可支持最大传输距离10km。支持热插拔，单纤双向传输，带数字诊断监控功能，支持商业级温度范围（0°C~70°C，-40°C~85°C）。 主要应用在10GBASE LR Ethernet以太网，10G LW Fibre Channel光纤通道等领域。

### 四、BIDI X2光模块

　　BIDI X2 TX1330nm/RX1270nm光模块，10GB BIDI X2单工SC 1270/1330nm 0〜160km光模块，BiDi X2系列单模收发器是用于双工光数据通信的小尺寸可插拔模块，如IEEE 802.3定义的10GBASE-LR /LWAE，支持热插拔。

## 单芯光模块如何工作

　　单芯光模块和传统双纤双向光模块的主要区别在于，单芯光模块配备了波分复用（WDM）耦合器，也就是双工器，根据波长的不同将在一根光纤上传输的数据进行汇合和分离。正因如此，单芯光模块也被认为是WDM光模块。

　　为了能够高效地工作，单芯光模块必须配对使用，通过调谐双工器以匹配发射器和接收器的期望波长，实现数据的双向传输。

## 单芯光模块的优缺点

　　单芯光模块的优点：

- 　1、行业中的竞争越来越激烈，很多竞争对手都在供应单芯光模块，市场的发展使得单芯光模块越来越普及，有必要跟上趋势。
- 　2、单芯光模块可以降低光纤布线基础设施的成本，因为它需要较少的光缆和较少的光纤接线板。
- 　3、单芯光模块在安装过程中可以节省更多宝贵的空间。

　　单芯光模块的缺点：

- 　1、必须成对使用，有一定的局限性。
- 　2、和一般光模块比较的话价格稍贵一些。

## 单芯光模块解决方案

　　目前常见的有四种封装类型的单芯光模块：SFP单芯光模块、SFP+单芯光模块、XFP单芯光模块和QSFP单芯光模块。其中SFP单芯光模块多用于千兆传输、SFP+单芯光模块和XFP单芯光模块专为双向10G（万兆）串行光数据通信而设计，而QSFP单芯光模块允许将40G连接的现有10G光纤基础设施重新使用，我们详细了解一下10G单芯光模块和40G单芯光模块。

### 1、10G（万兆）单芯光模块解决方案

　　10G单芯光模块的波长组合一般为1270nm / 1330nm，可用于20KM、40KM、60KM的传输距离。可以选择1270nm波长用于发送，1330nm波长用于接收的光模块或者1330nm波长用于发送，1270nm波长用于接收的光模块。10G单芯光模块主要优点是可以将传统光纤对的倍数提高一倍，如果使用10G的单芯光模块，也可以通过光纤对建立冗余，当使用带1310nm宽带端口的交换机时，这些10G单芯光模块也可用于CWDM项目。

### 2、40G单芯光模块解决方案

　　40G QSFP单芯光模块具有两个20G信道，每个信道在单个MMF光纤（OM3或OM4）上的两个波长上同时发送和接收。它允许现有的10G布线系统重新利用40G进行连接。这意味着它可以使用您今天使用的相同的10G设备，将40G速度带到接入层。相比之下，像思科QSFP-40G-SR4这样的一般QSFP 光模块需要新的跳线和配线架，因为连接器类型不同，并且光纤主干的尺寸需要增加四倍。

## 光模块型号

　　40G QSFP单芯光模通过一根双模光纤LC连接器（OM3或OM4 MMF）传输全双工40G流量。它能够重用10G光纤基础设施，也就是说，它使数据中心运营商能够升级到40G连接，而不会对以前的10G光缆厂进行任何更改，无论您是升级当前的数据中心还是建立新的数据中心，都可节省大量成本，可以较快的达到40G的速率。

## 总结

　　单纤BIDI光模块比较贵，但节省光纤资源，只需要1根光纤，对于光纤资源不足的用户来说是个更好的选择。而双纤光模块不需要配对使用，任意两个光模块都可以连接，价格比单纤BIDI光模块便宜，但是需要多用一跟光纤，如果光纤资源充足可以选择双纤光模块。因此双纤双向光模块和BIDI光模块使用起来效果是一样的，大家可以根据自己的需要进行选择。
